## Summary
- 当前工作区干净；`flutter analyze`、`flutter test`、`flutter build apk --debug` 均通过。
- 真机 `10.244.122.130:36515` 当前现场：无障碍服务在系统里是 `Enabled + Bound`，悬浮窗权限是 `allow`，但首页仍显示“服务未连接”，退后台再回前台等 5 秒仍不收敛。

  - 不保留调试日志；若排查中临时加日志，最终补丁前删除。
