# P7.1 加载配置列表计划

## Summary

- 本轮只做 P7 的第一小步：Flutter 侧“已加载 profile 列表”。
- P7.1 不新增 Android 多配置 Overlay，不显示多个悬浮执行控件，不改变当前 active profile 的基础多点执行。
- 本轮继续留在 `codex/p6-profile-management` 分支。

## Scope

本轮包含：

- 新增已加载 profile 状态模型。
- 新增 `multi_point.loaded_profile_ids_json` 持久化。
- 默认加载当前 active profile，避免升级后加载列表为空。
- 配置管理页展示已加载/未加载状态。
- 配置管理页支持加载、卸载 profile。
- 删除 profile 时自动收敛已加载列表。

本轮不包含：

- Android 多配置悬浮执行区。
- 多个悬浮执行控件。
- 执行模式、贴边展开按钮、按钮位置持久化。
- 并行任务和 P8 高级连招。

## Implementation Changes

- 新增 `LoadedMultiPointProfile`。
- `MultiPointProfileState` 增加 `loadedProfiles`，集中归一化缺失、重复、不可见和空列表。
- `MultiPointSettingsStore` 读写 `multi_point.loaded_profile_ids_json`，并兼容坏 JSON 兜底。
- `MultiPointProfilePage` 展示已加载数量和单个配置加载状态，菜单新增加载/卸载动作。
- 加载无启用点位的 profile 会被拒绝；卸载会保证至少保留 1 套已加载配置。
