# P7.2.4 多配置执行异常收尾专项验收

## Summary

- 本轮只做 P7.2.4：多配置执行异常收尾专项验收。
- 不新增 UI，不进入贴边展开、执行模式、暂停/继续控件或 P8 高级连招。
- 重点确认 P7.2 真实执行链路在关闭预览层、无障碍断开、悬浮窗权限撤销、隐藏当前执行配置时能安全结束任务。

## Scope

本轮包含：

- 运行某个配置时关闭执行控件预览，确认任务安全结束。
- 运行中关闭无障碍快捷开关，确认任务停止且服务恢复后可再次执行。
- 运行中撤销悬浮窗权限，确认控件关闭、任务停止且 App 不崩溃。
- 运行中隐藏或卸载当前执行配置，确认当前任务停止且其他控件仍可用。
- 汇总真机验收结果，并同步阶段管理文档。

本轮不包含：

- 贴边展开按钮。
- 执行模式 UI。
- 暂停/继续控件。
- 多任务并行。
- P8 长按、滑动、延迟和高级连招。

## Plan

1. 复查 P7.2.3 后当前阶段状态和相关收尾入口。
2. 给多人并行真机验收提供统一反馈模板。
3. 收集并整理真机专项结果。
4. 若发现可复现问题，只做最小修复并补充验证。
5. 无需修复时，直接记录验收结论并更新阶段管理文档。

## Acceptance Criteria

- 关闭执行控件预览后，当前 profile 任务结束，悬浮执行控件消失，可重新开启预览并再次执行。
- 无障碍服务运行中断开后，当前 profile 任务结束；重新开启无障碍服务后，可再次执行。
- 悬浮窗权限运行中撤销后，执行控件关闭，任务结束，App 不崩溃；恢复权限后可重新开启预览。
- 当前执行 profile 被隐藏或卸载后，当前任务结束，其他已加载执行控件仍可用。
- 验收过程未发现崩溃、闪退或任务残留。

## Assumptions

- 本阶段使用现有 P7.2.2/P7.2.3 的多配置执行控件和单任务模型。
- 真机专项结果由多人并行测试反馈汇总；没有发现问题时不改业务代码。
- P7.2.4 完成后，下一步再拆 P7.3，不把新 UI 混入本轮。
