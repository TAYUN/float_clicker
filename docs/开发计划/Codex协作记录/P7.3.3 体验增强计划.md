# P7.3.3 体验增强计划

## Summary

- 本文是 P7.3.3 计划草案，不代表功能已经实现。
- P7 核心能力已经完成并验证，当前只评估一个很小的体验增强。
- 候选方向有两个：恢复入口贴边吸附、防误触最小开关。
- 本轮推荐优先做 **恢复入口贴边吸附**，因为它延续 P7.3.2 的恢复入口拖动和持久化链路，改动范围更小，不需要新增 App UI。

## Candidate Evaluation

| 候选方向 | 收益 | 代价 | 结论 |
| --- | --- | --- | --- |
| 恢复入口贴边吸附 | 拖动后更贴合悬浮窗习惯，降低遮挡，继续保护恢复入口可见 | 主要集中在 Android 恢复入口坐标计算和 Flutter 持久化回传 | 推荐进入 P7.3.3 最小实现 |
| 防误触最小开关 | 能降低误点启动或停止任务的风险 | 需要新增配置入口、持久化、执行触发语义和真机验收矩阵 | 暂缓，后续单独拆阶段 |

## Recommended Scope

P7.3.3 推荐包含：

- 恢复入口拖动结束后自动吸附到屏幕左侧或右侧可见边缘。
- 吸附后坐标继续通过现有 `onMultiProfileExecutionLauncherPositionChanged` 回传 Flutter 持久化。
- 重新收起、关闭重开预览后恢复到上次吸附位置。
- 横竖屏或显示边界变化后，先校正到可见区域，再保持贴边语义。
- 保护 P7.3.2 已验证能力：恢复入口可拖动、可点击恢复、位置持久化、运行中恢复停止入口、无障碍断开提示。

P7.3.3 不包含：

- 新增 App 页面开关。
- 防误触开关、锁定位置、透明度、长按执行或二次确认。
- 单个 profile 执行控件贴边吸附。
- 记住收起状态。
- 暂停/继续控件。
- 多任务并行。
- P8 长按、滑动、延迟和高级连招。

## Plan

1. 复查 `OverlayWindowHelper` 当前可见边界、拖动回调和逻辑像素换算方式。
2. 在 Android 侧为恢复入口增加“拖动结束后吸附最近横向边缘”的坐标计算。
3. 吸附坐标仍使用逻辑像素，继续沿用 Flutter 已有恢复入口位置持久化 key。
4. 横竖屏或显示边界变化时，如果已有恢复入口坐标，则先按可见区域校正，再按当前屏幕宽度吸附到最近边缘。
5. 不新增 MethodChannel 方法；复用 `launcherPositionX/Y` 参数和 `onMultiProfileExecutionLauncherPositionChanged` 回调。
6. 补充自动化测试或可验证的单元边界；如 Android 侧无现成单测入口，则至少通过 `flutter analyze`、`flutter test`、`flutter build apk --debug` 和真机验收覆盖。
7. 实现完成后再发真机验收模板。

## Acceptance Criteria

- 收起执行控件组后，拖动恢复入口松手，入口会吸附到左侧或右侧可见边缘。
- 拖动到屏幕左半侧时吸附左边，拖动到右半侧时吸附右边。
- 吸附后点击恢复入口仍能展开执行控件组。
- 关闭并重新开启执行控件预览后，再次收起时恢复入口保持上次吸附边缘和纵向位置。
- 横竖屏切换后恢复入口仍保持可见，并继续贴近可见边缘。
- 配置运行中收起后，恢复入口吸附不影响展开并停止当前任务。
- P7.2.4 异常收尾和 P7.3.2 无障碍断开提示不回退。

## Assumptions

- 贴边吸附只作用于 P7.3 的恢复入口，不作用于多个 profile 执行控件。
- 吸附位置保存的是吸附后的逻辑像素坐标，不额外保存“左/右边”枚举。
- 恢复入口纵向位置不自动吸附，只在可见区域内校正。
- 如果屏幕宽度变化导致旧坐标越界，Android 侧按当前可见边界重新计算并回传 Flutter。

## Risks

- 可见边界在部分横屏应用中可能与系统返回的窗口指标存在差异，需要真机确认吸附后不会跑出屏幕。
- 如果吸附阈值或边缘间距不合适，可能影响用户把恢复入口放在中间区域的预期；本阶段明确采用贴边语义，不保留自由横向停靠。
- 防误触问题仍未解决，后续如果真实使用中误触频繁，需要另拆阶段处理。

## Implementation Changes

- `OverlayWindowHelper` 新增恢复入口可复用的横向贴边吸附坐标计算。
- `MultiProfileExecutionOverlayManager` 的恢复入口收起态刷新、拖动结束回调改为使用贴边吸附坐标。
- 贴边吸附继续沿用 P7.3.2 的 `launcherPositionX/Y` 参数和 `onMultiProfileExecutionLauncherPositionChanged` 回调，不新增 MethodChannel 方法。
- 首次默认位置仍不主动写入偏好；只有用户已有持久化坐标被吸附或边界校正、或拖动结束后，才回传 Flutter 保存。
