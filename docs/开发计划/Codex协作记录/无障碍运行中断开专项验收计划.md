# P5 无障碍运行中断开专项验收计划

## Summary
- 下一步聚焦 P5 剩余主风险：任务运行中关闭无障碍服务后的单点、多点收尾。
- 当前已有未提交改动必须保留：无障碍连接态修复代码、P5 记录更新，以及未跟踪的 `P5 权限状态同步下一步计划.md`。
- 本轮只做专项验收和明确 bug 修复；不进入 P6/P7/P8，不新增 UI 能力。

## Key Changes
- 执行前确认当前补丁基线：
  - `git status --short`
  - `flutter analyze`
  - `flutter test`
  - `flutter build apk --debug`
  - `adb connect 10.244.122.130:36515`
  - `adb install -r build\app\outputs\flutter-apk\app-debug.apk`
- 多点优先验收：
  - 首页确认无障碍“已连接”、悬浮窗“已开启”。
  - 进入多点页，开启多点悬浮层，启动执行任务。
  - 手动进入系统无障碍设置关闭 Float Clicker 服务，再回到 App。
  - 预期：多点任务结束，页面和悬浮控件不再显示 running；再次执行提示无障碍服务未连接；重新开启服务后可恢复执行。
- 单点随后验收：
  - 开启单点悬浮层，启动执行任务。
  - 手动关闭无障碍服务，再回到 App。
  - 预期：单点任务结束，页面、首页和悬浮控件回到非执行态；重新开启服务后可再次执行。
- 若发现明确不同步或窗口残留，只做最小修复：
  - 优先检查 `MainActivity` 的 `accessibilityConnectionListener`、单点/多点 `handleAccessibilityServiceDisconnected()`、Flutter 页面权限事件处理。
  - 保持 MethodChannel 字段和错误码不变。
  - 不保留临时日志。
