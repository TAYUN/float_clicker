# P7.2.2 执行控件绑定配置任务计划

## Summary

- 本轮只做 P7.2 的第二小步：点击某个多配置执行控件时，执行该控件绑定的 `MultiPointProfile`。
- 继续沿用 P7.2.1 已验证的多控件显示、拖动、横竖屏可见和单控件显示/隐藏能力。
- 第一版仍采用单任务执行模型：同一时间只允许一个 profile 任务运行。

## Scope

本轮包含：

- Flutter 侧向 Android 传递已显示 profile 的轻量执行快照：`profileId`、`displayName`、点位、点击参数。
- Android 侧执行控件点击后，根据 `profileId` 找到对应任务快照并启动多点调度。
- 正在执行的控件再次点击时，结束当前任务。
- 其他控件在任务运行中拒绝启动，并给出“已有任务运行”的明确提示。
- 执行完成、失败、结束或无障碍断开后，控件状态回到可再次执行。
- 继续保护单点模式和基础多点编辑悬浮层互斥边界。

本轮不包含：

- 多任务并行执行。
- 暂停/继续按钮、完整控制条和贴边展开按钮。
- 执行控件位置持久化。
- 执行中置灰样式细化、透明度、锁定、防误触配置。
- P8 长按、滑动、延迟和高级连招。

## Plan

1. 定义 P7.2.2 的轻量 profile 执行 DTO，复用现有 `MultiPointTargetState` 和点击参数字段。
2. Flutter 侧组装已显示 profile 的完整执行参数，并通过现有 `show/updateMultiProfileExecutionOverlay` 同步给 Android。
3. Android `MultiProfileExecutionOverlayManager` 保存 profile 执行快照，并把控件点击从 Toast 改为启动/停止对应任务。
4. 复用 `MultiPointClickScheduler`，每次只运行一个 profile 任务。
5. 原生侧维护 `runningProfileId`，用于阻止其他控件同时启动。
6. 补充 Flutter widget 测试和 Android debug build 验证。
7. 真机验证一个 profile 可执行、另一个 profile 被拒绝、当前执行控件再次点击可停止。

## Acceptance Criteria

- 点击已显示控件 A，可以按 A 的点位和点击参数执行任务。
- 控件 A 运行中再次点击，可以停止 A 的任务。
- 控件 A 运行中点击控件 B，不启动 B，并提示当前已有任务运行。
- 执行完成或停止后，可以点击控件 B 执行 B。
- 无启用点位的配置仍不能显示或执行。
- 关闭执行控件预览层时，正在执行的任务被安全结束。
- 单点模式最小回归通过：开启单点悬浮层、执行、结束、关闭。
- 自动化检查至少通过 `flutter analyze`、`flutter test`、`flutter build apk --debug`。

## Assumptions

- P7.2.2 不改变基础多点页的 active profile 执行语义；页面里的“执行任务”仍执行当前 active profile。
- 多配置执行控件使用 profile 自己的点位和点击参数，不读取当前页面正在编辑的临时状态，除非该 profile 已保存。
- 执行控件第一版只提供开始/停止，不提供暂停/继续。
- 控件运行状态可以先用 Toast 和内部状态保护完成，视觉强化留给后续小阶段。

## Risks

- 复用 `MultiPointClickScheduler` 时要保证关闭预览层、无障碍断开和权限撤销都能安全结束任务。
- profile 快照如果和 Flutter 最新编辑状态不同步，用户可能以为控件执行的是未保存改动；本轮需要在开启/更新预览层前保存当前 active profile。
- 多控件真实执行会影响底层应用，真机验收必须确认点击确实落到底层应用而不是被控件窗口消费。

## Implementation Changes

- Flutter `show/updateMultiProfileExecutionOverlay` 参数从轻量身份扩展为 profile 执行快照，包含 `settings` 和 `targets`。
- 开启执行控件预览前先保存当前 active profile；预览层开启后，点位和设置编辑会同步刷新原生执行快照。
- Android `LoadedMultiPointProfileState` 解析完整 profile 快照，并过滤无启用点位的配置。
- Android `MultiProfileExecutionOverlayManager` 复用 `MultiPointClickScheduler` 执行绑定 profile。
- 原生侧新增 `runningProfileId` 单任务保护：当前控件再次点击结束任务，其他控件点击提示已有任务运行。
- 关闭执行控件预览、悬浮窗权限撤销、无障碍服务断开、运行中隐藏当前 profile 时，会安全结束当前任务。
- 执行中的 profile 控件显示“停止 配置名”，其他控件降低透明度，视觉强化后续仍可继续细化。
