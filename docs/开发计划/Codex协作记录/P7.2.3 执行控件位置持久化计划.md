# P7.2.3 执行控件位置持久化计划

## Summary

- 本轮只做 P7.2.3：多配置执行控件拖动后保存位置，并在刷新或重新开启预览层时恢复。
- 继续沿用 P7.2.1 多控件显示和 P7.2.2 profile 绑定真实执行能力。
- 位置属于“已加载执行控件状态”，不写入 `MultiPointProfile` 点位坐标。

## Scope

本轮包含：

- 新增执行控件位置持久化模型。
- 新增 `multi_point.loaded_profile_buttons_json` 或等价 key 保存 profileId 与按钮坐标。
- Flutter 展示或更新多配置执行控件时，把已保存按钮坐标传给 Android。
- Android 执行控件拖动结束后，通过 MethodChannel 回传 `profileId`、`x`、`y`。
- Flutter 接收回调并保存，下次刷新或重新开启预览层恢复位置。
- 加载、卸载、删除 profile 时收敛无效按钮位置。

本轮不包含：

- 贴边吸附、贴边展开按钮。
- 控件面板折叠、分组、滚动列表。
- 暂停/继续按钮。
- 位置云同步、导入导出。
- P8 高级连招。

## Plan

1. 在 Flutter 多点模型中新增 loaded profile button position 状态。
2. 扩展 `MultiPointSettingsStore` 读写按钮位置，并在 profile 删除或卸载时清理无效位置。
3. 扩展 Flutter MethodChannel 参数，随 `loadedProfiles` 传入 `buttonPositionX/Y`。
4. Android `LoadedMultiPointProfileState` 解析初始按钮位置。
5. Android `MultiProfileExecutionOverlayManager` 拖动控件后回传 `onLoadedProfileButtonPositionChanged`。
6. Flutter `AndroidPermissionService` 增加位置回调分发，`MultiPointPage` 保存对应位置并刷新本地状态。
7. 补充 widget/store 测试和自动化验证。

## Acceptance Criteria

- 拖动控件 A 后，关闭并重新开启执行控件预览，A 回到上次位置。
- 拖动控件 A 后刷新 loaded profiles，A 不跳回默认位置。
- 控件 B 的位置不被 A 的拖动覆盖。
- 卸载或删除某个 profile 后，对应位置数据被收敛，不影响剩余控件。
- 横竖屏后仍先校正到可见区域，后续回传保存校正后位置。
- 自动化检查通过 `flutter analyze`、`flutter test`、`flutter build apk --debug`。

## Assumptions

- 坐标仍使用 Flutter 逻辑像素，与现有点位和控制条位置语义一致。
- 默认位置继续由 Android 根据顺序纵向排列生成；只有保存过位置的控件才使用持久化坐标。
- P7.2.3 不改变执行调度和单任务互斥语义。

## Risks

- 位置回传和 profile 列表刷新可能同帧发生，需要避免旧状态覆盖新 loaded profile 列表。
- 横竖屏校正后的回传会更新持久化位置，属于既有悬浮窗边界策略。
- 如果执行中拖动控件后立刻停止任务，需要保证位置保存和执行状态互不干扰。

## Implementation Changes

- `LoadedMultiPointProfile` 新增 `buttonPositionX`、`buttonPositionY`，随 loaded profile 状态一起持久化。
- Flutter `show/updateMultiProfileExecutionOverlay` 会把已保存的执行控件位置传给 Android。
- Android `LoadedMultiPointProfileState` 解析 `buttonPositionX/Y`，多配置执行控件优先使用已保存位置。
- Android 执行控件拖动结束后回传 `onLoadedProfileButtonPositionChanged`。
- Flutter `AndroidPermissionService` 新增执行控件位置回调分发，`MultiPointPage` 接收后保存到 profile state。
- 已加载 profile 删除、卸载或坏数据收敛继续复用现有 `loadedProfiles` 归一化逻辑。
- 根据真机复验反馈，隐藏同一个执行控件时不再删除 loaded 条目，而是保留 `isVisible=false` 和按钮位置；重新显示同一控件时恢复上次位置。
