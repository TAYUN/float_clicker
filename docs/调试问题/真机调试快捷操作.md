# 真机调试快捷操作

## 1. 无障碍快捷开关

部分真机右下角会显示系统无障碍快捷浮标。Float Clicker 调试时，这个浮标就是本应用无障碍服务的快捷开启/关闭入口，点击浮标可以快捷切换本应用的无障碍权限的开启/关闭。

用途：

- 运行中断开无障碍服务专项验收。
- 快速复现“无障碍服务未连接”执行拒绝。
- 重新开启服务后验证单点和多点是否能恢复执行。

注意：

- 点击该快捷浮标后，页面权限卡片可能存在短暂刷新过程，不能只凭首帧文案判断异常。
- 调试结论优先结合页面实际可操作性、悬浮控件状态和 `dumpsys accessibility` 判断。
- 当前设备上可以用以下命令确认系统侧状态：

```powershell
adb shell dumpsys accessibility
```

重点观察：

```text
Enabled services
Bound services
com.example.float_clicker/com.example.float_clicker.FloatClickerAccessibilityService
```

## 2. 记录建议

真机验收中切换无障碍服务时，建议同时记录：

- 设备型号和 Android 版本。
- 操作前后页面文案和悬浮控件状态。
- `dumpsys accessibility` 中 `Enabled services` 和 `Bound services`。
- 是否通过点击右下角无障碍快捷浮标切换服务。
