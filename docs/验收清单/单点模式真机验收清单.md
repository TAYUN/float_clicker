# 单点模式真机验收清单

## 验收前准备

- 安装最新 debug 包。
- 开启悬浮窗权限。
- 开启 Float Clicker 无障碍服务，并确认首页显示“已连接”。
- 在设置页分别准备一组有限次数任务和一组无限循环任务。

## Flutter 页面状态

- 首页权限卡片能区分“无障碍未授权”和“已授权但服务未连接”。
- 首页“当前运行状态”能显示未启动、单点模式已开启、执行中、已暂停。
- 单点页进入时能读取当前原生悬浮窗状态，而不是只显示本次页面内状态。
- 从系统设置或其他 App 回到单点页后，权限状态和任务状态会刷新。

## 普通模式

- 开启单点模式后显示点击点和完整控制条。
- 点击点可以拖动，松手后位置能保存。
- 控制条可以拖动，松手后位置能保存。
- 控制条“执行”会开始点击；再次进入页面时进度能同步显示。
- 执行中点击“暂停”进入暂停态，点击“继续”从原进度继续。
- 点击“结束”结束任务并清空进度，但不关闭单点模式。
- 点击“关闭”移除所有悬浮组件并结束任务。

## 简洁模式

- 开启后显示点击点和可收起控制条。
- 点击收起入口后，完整控制条消失，显示收起图标和独立执行控件。
- 收起图标可以拖动，点击后恢复完整控制条。
- 独立执行控件单击可执行、暂停、继续。
- 独立执行控件长按可结束任务。
- 收起状态和各组件位置能持久化。

## 极简模式

- 开启后只显示点击点和独立执行控件。
- 独立执行控件可以拖动并持久化位置。
- 单击独立执行控件可执行、暂停、继续。
- 长按独立执行控件可结束任务。
- 不应出现完整控制条或收起图标。

## 横竖屏与贴边

- 在本 App 竖屏和横屏之间切换，点击点、控制条、收起图标、独立执行控件都保持可见。
- 竖屏顶部不会越过状态栏，左侧可以贴到 `0`。
- 横屏左侧和上侧可以贴到 `0`，右侧不再卡在屏幕中间。
- 从本 App 竖屏切到其他横屏 App 后，悬浮组件仍能继续拖动并尽量贴边。
- 首次拖动不会出现“瞬间跳到手指右下方”的偏移。

## 权限与异常收尾

- 未开启无障碍服务时，页面“执行任务”和悬浮控件“执行”都不会静默失败，应显示失败提示。
- 任务执行中关闭无障碍服务，任务应结束，页面或首页状态应回到非执行态。
- 单点模式开启中撤销悬浮窗权限，所有悬浮组件应消失，页面应回到未启动。
- 权限恢复后重新开启单点模式，旧位置和交互模式仍能按保存值恢复。
